PAINEL · MESTRE DA MANIPULAÇÃO

Falta só conectar o banco de dados (Supabase, gratuito). Leva uns 5 minutos:

  1. Crie uma conta em supabase.com e um projeto novo (guarde a senha do banco).
  2. Em SQL Editor, cole o conteúdo de supabase-setup.sql (troque SEU_EMAIL_AQUI pelo seu e-mail) e clique em Run.
  3. Em Authentication → Users → Add user, crie o seu usuário (o mesmo e-mail e uma senha forte). Em Sign In / Providers, desative "Allow new users to sign up".
  4. Em Project Settings → API, copie a Project URL e a chave anon public para o arquivo config.js.
  5. Publique de novo. Pronto: o painel passa a pedir seu login.
